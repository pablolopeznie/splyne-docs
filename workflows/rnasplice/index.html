    Differential Splicing¶

    This page documents the Splyne integration for nf-core/rnasplice. For details on workflow functionalities, visit the official documentation of the pipeline in nf-core website.

    Purpose¶

    The module is focused on detecting differential splicing events between groups from RNA-seq data using a standardized nf-core workflow.

    Prerequisites¶

    • Input files must be uploaded and validated.
    • The samplesheet must be saved.
    • Reference resources must be available.
    • Experimental conditions must be correctly represented in the samplesheet.
    • A contrastsheet must define the comparison of interest.
    • A Nextflow dependency profile must be available, preferably Apptainer or Docker.

    Inputs¶

    The workflow uses one of the available samplesheets:

    • temp_files/samplesheet.csv for raw input files.
    • temp_files/clean_samplesheet.csv when fastp preprocessing has generated cleaned reads.

    Splyne also uses a contrastsheet for treatment-control comparisons.

    Configuration¶

    The module exposes selected workflow parameters through the advanced options panel. Users can review samplesheet and contrastsheet content before execution.

    The default contrast follows a treatment-versus-control structure and should be reviewed against the experimental design. However, despite this naming convention, it can be used to compare any two-level groups. This structure is mainly adopted as a bioinformatics convention, but there is no limitation preventing other types of contrast, such as sex-based comparisons, time1 versus time2, etc.

    Parameters¶

    UI parameter Pipeline argument Default Possible values Consequence
    Reference genome fixed reference context GRCh38 Fixed, read-only Documents the genome assembly expected by the bundled reference directory. Changing it is not supported from the UI.
    Annotation version --gencode context Gencode v46 - Ensembl 112 Fixed, read-only Documents the annotation release used by the workflow.
    Dependency profile -profile apptainer docker, conda, apptainer Selects the dependency backend used by Nextflow.
    Contrastsheet --contrasts temp_files/contrastsheet.csv Generated CSV file Defines treatment-control comparisons. Incorrect contrasts lead to biologically invalid comparisons.
    Sample sheet --input Raw samplesheet by default; clean if selected and available raw_samplesheet, clean_samplesheet Chooses whether rnasplice receives original reads or fastp-filtered reads.
    Working directory -work-dir temp_files/nf-core-rnasplice-temp/run Any user-selected local directory Controls where Nextflow writes intermediate files.
    Store BAM alignments --save-align-intermeds plus result filtering false true, false Publishes and archives selected sorted BAM and BAI files. Increases disk usage substantially.
    Save R objects result filtering for *.rds false true, false Adds R serialized objects to the archived outputs. Useful for downstream R analysis.
    Minimum samples TE --min_samps_feature_expr Half of the available samples, rounded upward for small datasets Integer from 0 to number of samples Minimum number of samples in which a transcript feature must satisfy expression filtering. Higher values are stricter.
    Minimum transcript counts --min_feature_expr 10 Integer from 0 to 100 Minimum transcript-level count threshold for DEXSeq filtering. Higher values remove low-expression features.
    Minimum samples TP --min_samps_feature_prop Half of the available samples, rounded upward for small datasets Integer from 0 to number of samples Minimum number of samples in which a transcript proportion must satisfy filtering. Higher values are stricter.
    Minimum transcript proportion --min_feature_prop 0.1 Decimal from 0.0 to 1.0 Minimum transcript usage proportion. Higher values remove low-usage transcripts.
    Minimum samples GE --min_samps_gene_expr ceil(number_of_samples / 2) Integer from 0 to number of samples Minimum number of samples in which a gene must satisfy expression filtering.
    Minimum gene counts --min_gene_expr 10 Integer from 0 to 100 Minimum gene-level count threshold. Higher values remove low-expression genes.
    Reads length --rmats_read_len Workflow default in the app, usually 100 Integer from 40 to 300 Read length used by rMATS. This should match the sequencing data to avoid inaccurate splicing estimates.
    Cluster analysis --clusterevents_local_event and --clusterevents_isoform remain enabled only when selected false true, false Enables SUPPA clustering features marked as beta. When disabled, Splyne explicitly turns these options off because they are considered problematic.
    rMATS paired model --rmats_paired_stats false when group sizes are not balanced Automatic Automatic from sample conditions Splyne disables paired statistics when the condition groups are not suitable for a paired model.

    Execution¶

    Splyne builds the nextflow run nf-core/rnasplice command from the selected UI parameters and submits it through the shared job manager as a declarative Workflow object.

    During execution, Splyne monitors the active process, displays the Nextflow log and prevents conflicting long-running jobs from being launched.

    Outputs¶

    Results are packaged after completion and made available from Run History. Output filtering focuses on interpretable reports, tables, plots and workflow summary artifacts. See Results > Filtering logic for more information on ouput filtration.

    Notes and Limitations¶

    Differential splicing results depend strongly on correct experimental metadata. Users should verify sample conditions and contrasts before launch.
